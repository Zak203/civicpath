# CivicPath POC

Prototype web mobile navigable reconstruit a partir des maquettes du PDF.

## Lancer

```sh
npm run dev
```

URL locale par defaut : `http://localhost:5173`.

## Ecrans inclus

- Onboarding et choix des sujets
- Accueil avec filtre et liste des issues
- Detail d'une issue et suivi du processus
- Formulaire d'opinion en 3 etapes
- Creation d'un projet en 5 etapes
- My activity avec statuts et timeline
- Profil et preferences de suivi

## Notes

Les images du PDF restent dans `public/screens` comme references de maquette, mais l'application rendue est en HTML/CSS/JS interactif.
